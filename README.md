# AgroAI – Smart Plant Disease Detector

## Project Overview
AgroAI is a modern React website for detecting plant diseases using AI. It features a futuristic agricultural dashboard with responsive design, smooth animations, glassmorphism, and a dark mode toggle.

## Tech Stack
- React
- Vite
- Tailwind CSS
- Framer Motion

## Installation
1. Install Node.js if needed.
2. Install dependencies:
   ```powershell
   npm install
   ```
3. Start the development server:
   ```powershell
   npm run dev
   ```
4. Open the local URL shown in your terminal.

## Features
- Responsive landing page with modern dashboard design
- Dark mode toggle
- Smooth Framer Motion animations
- Rounded cards and glassmorphism styling
- AI farming illustration and hero section

## Project Structure
- `index.html` — Vite entry HTML
- `package.json` — React + Tailwind dependencies
- `tailwind.config.js` — Tailwind configuration
- `src/main.jsx` — React entry point
- `src/App.jsx` — Homepage UI
- `src/index.css` — Tailwind utilities and custom theme styles

## Notes
This website is a frontend prototype. If you want to connect it to an AI model or detection API, add the upload flow and backend integration under the `Detect Disease` section.
